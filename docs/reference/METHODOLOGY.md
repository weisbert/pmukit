## Core architecture

- **Linear 2-port LTI model = Zout(s) + PSRR(s) + shaped Norton noise + discrete spurs + a SEPARATE nonlinear DC/dropout table** — **WORKS (conditional).** The FORM is physically correct for disturbances ABOVE the loop UGB (loop open → vout = the open-loop passive output network). FORM holds within the declared envelope; the historical VALIDATION was in-sample/block-level only (see Validation below).
- **The irreducible kernel = ONE phase-accurate, OP-parameterized Zout(s)** — **WORKS (the central insight).** All four observables are the SAME Zout driven by different sources: PSRR = Y_couple·Zout·vin; noise Sv = |Zout|²·S_in; transient = IFT(Zout·i_load) (carries NO new info beyond Zout in the linear regime); spur = Zout·i_spur. Only DC/dropout is a genuinely separate nonlinear object. ⇒ a Zout error is COMMON-MODE across all four.
- **One emitted instance, layered (NOT split per use-case)** — **ADOPTED.** Deployment needs ONE `.va`/`.lib` (a system PSS/HB run presents Zout+PSRR+noise+spur simultaneously on one node — separate fits would let them disagree about the one physical Zout = unphysical). Characterization is already per-block. Form = one shared phase-first identifiability-gated kernel + per-use shells + a use-case-resolved scorecard.
- **Per-block swappable blocks + data-driven topology selectors** — **WORKS.** 4+2+2 blocks compose vs a 4×2×2 monolithic cross-product. Confirmed by an independent survey to be the field's recommended composite.
- **PVT = route A: characterize each PVT cell separately → fit separately → emit `.lib` SECTIONS** (tt_25c_1v05, ss_125c_0v95…), Cadence corner setup picks the section. **ADOPTED** (deliberately avoids a new overfitting surface). Cross-PVT interpolation **REJECTED**; continuous PTAT-ish i(T) is the only exception.

## Zout block

- **Multi-start bounded TRF + R_pl damping resistor + optional 2nd parallel R-L branch** (engaged only when it beats 1-branch by >40%) — **WORKS.** R_pl→∞ = resonant peak; finite R_pl = resistive plateau (one DOF generalizes peaked↔plateau). Branch B closes V3 (3.45→0.78 dB).
- **Higher-order (L‖R) ladder in series** (Ra + N×(L‖R) + Cout/ESR; magnitude-shape gate) — **WORKS** for a rising-then-plateau resistive shelf (the real the real part rails). Productionized through the in-situ pipeline, byte-identical when the `extra` list is absent.
- **Single inductor (La‖Rpl)+Cout to model a rising shelf** — **FAILED** (can't make rising-then-plateau → mislocates the corner ~70×, to 447 kHz).
- **Cout/ESR auto-extract from the capacitive band** (∠Z<−45°, C=−1/(ω·Im Z)) — **WORKS** within a few % over 100 pF–10 nF, EXCEPT high-ESR/cap-less parts (v1 381 vs 1000 pF; 30 Ω ESR floors the HF tail). Joint-LS Cout/ESR for those — **REJECTED** (underdetermined when ESR≫output-R, the cap is near-invisible → diverges; reverted to median/keep-best).
- **Unbounded LM + argmax-of-flat init** — **REJECTED** (diverged: cout10n R_a=32 MΩ; V1 92 dB spurious peak; v2 Cout → 1e269 F).
- **Passive-by-construction RLC** — **WORKS** (the #1 HB-convergence lever). It CANNOT reproduce a genuinely non-passive GT (v3 Re(Z)<0, ~−0.25 Ω floor); that residual is a documented FLOOR, not a bug. Non-passive controlled-source realization **REJECTED** (HB-stability risk).
- **Branch-A regulation must be the STIFF R_a resistor (`V(nA,vrg) <+ Ra*I`), NOT a saturating "DC current compliance"** — **REJECTED 2026-07-01** (`max(-Icomp,min(Icomp,V/Ra))` / `Icomp*tanh`). The clamp's knee is a **voltage** `Icomp·Ra`; with the near-zero fitted Ra (~0.02–0.1 Ω) that's **~1–5 mV**, so a few mV off vreg the regulation becomes a **zero-conductance current source** → the output DC pin is lost → **FF-corner runaway (Spectre: 2.31e6 V) / non-convergence** (TT/SS only survive by staying in the ±mV sliver). The resistor holds 1/Ra everywhere and is bit-identical in Zout/PSRR/noise + validated large-signal. LESSON: a current-limit on a near-ideal source is only well-conditioned if the knee VOLTAGE ≫ any excursion the DC solve traverses; a real dropout/current-limit is stage-2b and must be a one-sided, conductance-preserving soft limit. (The "unbounded DC fight" it targeted is handled by the PSRR supply auto-track instead. `harness/test_pvt_robust_emit.py` locks this.)
- **Zout shelf fit = sign-agnostic SHAPE gate, magnitude-only, cap-open** — **WORKS.** The old "resonance mislocated / Q2000" diagnosis was WRONG (a metric artifact on a loop-active negative-real shelf). importmp passivity-normalizes Zout to Re≥0, so the gate must be shape-only (Q>3 + ipk≥0.6N + plateau>0.6peak), not Re-sign-dependent.

## PSRR block

- **Identify i_c = H_psrr/Zout by Sanathanan–Koerner rational fit (freq-scaled, relative-weighted); realize as a bank of signed first-order real-pole sections** — **WORKS.** The earlier claim "PSRR doesn't factor as i_c·Zout" was WRONG/REFUTED — it was a fit-method failure (shelf insufficient order; naive fit won't converge over 60 dB), not structural.
- **One signed complex-conjugate 2nd-order section, AAA-initialized + least_squares-polished on the realizable form** — **WORKS** for non-min-phase parts (v4 mag to 0.04–0.06 dB; 25° residual phase remains). N2=1 is the sweet spot. Keep a 1-section shelf if min-phase fits (no regression on 9 variants); the 3-real bank polish must be UNGATED (was wrongly `if CFT>0`).
- **Raw AAA poles dumped into the model** — **REJECTED** (over-fits: 3–6 spurious pairs, Q~1700). AAA is an INITIALIZER only.
- **Ranking a real PSRR notch fit by analytic residual** — **REJECTED** (low analytic residual but huge realized phase error from fragile pole-zero cancellation). Always realize + score, never rank by analytic residual.
- **PSRR is NOT non-minimum-phase by default** — the Hilbert "non-min-phase" reading was an artifact of sparse silicon AC points.
- **AAA complex-section initializer on sparse silicon AC** — **FAILED / OPEN** — the remaining the real part **pll PSRR blocker** (resid 3.16 > shelf 1.06, ~47-pt sweep, phase RMS ~51°). Needs a robust complex-section initializer for sparse real AC.
- **Two separated PSRR notches in a single-loop integrated LDO** — **REJECTED (physics).** Two feedforward paths merge into one effective notch; an on-chip LC trap at 10s of MHz needs unphysical µH. The single-complex-pair block matches single-loop physics; exceeding it needs a cascade/multi-loop topology.
- **A rational PSRR fit that EMITS large near-cancelling first-order residue pairs breaks a COUPLED `oschb`, even though AC/analytic are perfect.** real rail B fit → `G1=+17.23 / G3=−17.23` (poles 0.004 % apart, DC-cancel to 0.3 %); alone or in a driven-HB these are harmless, but in the real oschb the ±17.2 S VCCS pair is a near-null-space direction in the SHARED supply-node harmonic Jacobian → singular columns surface at the PACKAGE nport / real transistors sharing the node, not at the model (the classic "the behavioral block converges standalone but not in the system"; a real LDO in the same slot converges). **RULE: realize any low-f 2nd-order PSRR section, AND any large near-cancelling `|G_i|` doublet, as ONE small-coefficient gm-C biquad — never as a synthesized R-L-C (huge L/C) nor as parallel large-residue first-order sections.** Detector: scan the emitted per-rail `|G_i|` for any `>~1` or a cancelling pair. (Distinct from the "rank by analytic residual" rejection above — that was FIT ranking; this is EMIT realization.) → TOOL_FACTS §Spectre/Verilog-A; `docs/threads/hb-oschb-conditioning.md`.

## Noise block

- **Decoupled Norton-@vout: In = Sv_meas/|Zout_model|, In² = white + 6 Lorentzians fit in the LOG domain jointly over 3 corners (shared corner freqs, per-corner amplitudes); realize as white-R + 6 R‖C VCCS sections** — **WORKS.**
- **log-AMPLITUDE noise fit** — **WORKS**; replaced linear-LS-in-power (LF flicker inflated the white floor 5–30×; real flicker af~0.85 sub-1/f).
- **CAVEAT — "decoupled" is a MISLABEL, not a defect.** It's an algebraic round-trip (In=Sv/|Z| → Sv=In·|Z|) that decouples SYNTHESIS, not PHYSICS — a Zout error leaks identically into noise. DO NOT "fix" the round-trip (the physics is correct); relabel it and score Sv vs GT end-to-end.
- **Series-voltage noise in branch A riding the Cout divider** — **REJECTED** (base-specific + coupled to Zout synthesis; adding branch B for V3 perturbed noise 5.6→21.8 dB). EXCEPT: a **HYBRID series-voltage bank WORKS for loop-shaped rails** (Norton can't hold In=Sv/|Zout| for the pll/vco ~11 dB rails; synthetic DUTs stay Norton).
- **The hybrid series-voltage bank must actually be EMITTED — BUG FIXED 2026-07-02.** The hybrid fit (`fit_model.fit_noise_hybrid`: `Vn²=snw²·KT4·NRk + Σ snk²·KT4·NRk/(1+(f/fvk)²)`, reaching vout via `T=Zout/ZA`) WORKED, but `emit_pmu_model` only ever emitted the NORTON form (`I(o,gnd)<+gn·V(nk)`). For a hybrid rail `fit_multiport` sets `nfk=[]`, so the emit's Lorentzian loop produced ZERO sections and `snw/sn_k` were dropped — the deployed `.va` shipped ONLY the white Norton floor `gnw`, so the entire 1/f FLICKER (the low-freq-dominant term, real rail B Vn(100Hz)≈28 µV/√Hz vs 90 nV at 1 MHz, ~306× 1/f) VANISHED — the LDO noise "disappeared" at 100 Hz in a deployed .noise/HB-PN sim (user-reported). Fix: `_voltage_body` now emits, when `nmode=="hybrid"`, the series-voltage bank — white node `nvw` + Lorentzian nodes `nvk` at the `nfkv` poles (each `white_noise()` shaped by NRk‖Cnv), inserted as a series EMF `snw·V(nvw)+Σ sn_k·V(nvk)` in the branch-A R_a regulation (reaches vout via Zout/ZA, EXACTLY the fit's T) — PLUS the kept Norton white `gnw` (the 2nd hybrid term). Gated on `nmode` → Norton rails BYTE-IDENTICAL; the series EMF is 0 at DC/AC (noise-only) → Zout/PSRR/DC unchanged. Both literal + scheduled paths (snw/sn_k are load-independent → baked from the nominal corner). VALIDATED: the emitted real rail B Spectre `.noise` now matches the GT to <10% across 100 Hz–1 MHz (100 Hz: 26.5 µV vs GT 26.7). `harness/test_emit_noise_hybrid.py`; DATA §11.
- **`flicker_noise()` / `noise_table()` for the 1/f tail** — **REJECTED** (no byte-matching ngspice analog → forfeits the 9e-6 cross-engine lock; the free Lorentzian bank is equal-or-better).
- **Rail intrinsic-output noise is EMITTED on the 4kT@300K FIT basis, NOT 4kT·$temperature — FIXED 2026-07-02 (E2/M12).** The gains are backed out at 300 K (`fit_model.KT4`), so emitting `white_noise(4kT·$temperature)` re-scaled the output PSD by `$temperature/300` → **+0.39 dB at the 55 °C char/deploy temp** plus a non-physical `sqrt(T/300)` cross-temp amplitude scaling on GT noise that is ~T-independent (BSIM3 flicker + loop-shaped), while the SAME `.va`'s SINK noise was a T-independent literal (one artifact, two temperature conventions). Fix: pin every RAIL `white_noise` first arg to `4kT·300.0` in BOTH emit paths (`emit_pmu_model._voltage_body` + `fit_model.emit_va`) → the `.va` reproduces the fitted spectrum EXACTLY at all T, and unifies with the sink literal. **CROSSVAL byte-identical**: the `.lib` rail noise is bare SPICE resistors (`fit_model._noise_net`, no `white_noise` term) so it is untouched — but that means the `.lib` rail noise still tracks ngspice's global sim temp (there is no fixed-PSD noise primitive inside a subckt); at 27 °C the two agree within 0.002 dB, they diverge hot/cold (a genuine ngspice limitation, not a bug → BACKLOG). Do NOT use 328.15 (that re-introduces the +0.39 dB); the correct constant is the 300 K fit basis. `harness/test_emit_noise_temp.py` (always-on string lock: `white_noise(4*` + backtick + `P_K*300.0` present, no `$temperature` in any rail `white_noise`).
- **Spur sampling rule** — **LOCKED.** `.noise`/AC sweeps MUST sample the spur center + very-short-step points (0.05…4×HWHM, Q-aware) around it, else the narrow spur is stepped over (54× miss measured).

## Spur block

- **Deterministic vout current tones `Isp 0 vout`, I_k = vout_amp_k/|Zout_model(f_k)|, characterized by transient-FFT (NOT `.noise`)** — **WORKS (0.00 dB).** Split detected lines into fundamentals vs IM/harmonic products (the linear model emits only fundamentals; the user's nonlinearity regenerates IM). PSS/HB manifest: GCD-fold commensurate tones vs declare separate incommensurate fundamentals. External supply/bias spurs are NOT emitted — they ride the PSRR path.

## Load dependence

- **Parameter scheduling: each param a clamped quadratic in ln(iload)** — **WORKS as the default; FAILS at the edge.** The 3-corner, 0-residual-DOF quadratic is the PROVEN OVERFIT LOCUS (in-corner error ≡ 0, carries no generalization info; held-out 20–30×; flat/frozen outside [20µ,250µ] via clamp). Band-aids (_pexpr clamp, MIN_LOG_GAP, branch-B 40% gate) censor the symptom, not the correctness — they are local heuristics, not AIC/BIC.
- **The rail grade is `max()` OVER CORNERS → adding load corners can only LOWER the rollup; a "worse" grade on richer coverage is NOT a regression.** The the real part's complete run (DATA §5) confirmed the ln(iload) edge-failure on Zout specifically: the (L‖R) ladder places the RISE-CORNER right at nominal-and-heavier load (≤0.34 dB) but MISLOCATES it at the LIGHT-load edge (100–300 µA → 1.1–2.4 dB; model peak 1.78/4.47 MHz vs GT 10 MHz). ⇒ a single-OP model fit at nominal is SILENTLY optimistic at light load (the LOAD-axis mirror of the pvt "single-corner optimistic at stressed corners" finding). The fix is a load-dependent rise-corner (more light-load corners, or physically-constrained per-corner L‖R), NOT a scoring change. → BACKLOG (LOCO / few-corner limit).

## Large-signal / recovery (the real rail A thread)

In the order it evolved — most are RETIRED; read top-to-bottom to see why:
- **Hand-tuned `la_override` + Lreg‖Rreg recovery network (La=120 µH)** — **REJECTED** (a crutch; a real user can't know La/Lreg; must be fitted). AC-inconsistent (La120 |Z|@10MHz=558 Ω vs measured ~160).
- **"Drop slew, go pure LTI with the deployment decap"** — **SUPERSEDED/RETRACTED.**
- **Fit La + recovery from AC Zout alone** — **SUPERSEDED** (a single inductor can't make the rising shelf; AC gives 24 µH, the transient seemed to want ~120 µH = the small-signal-vs-large-signal gap).
- **slew + recovery network (compensated.va) under decap** — **REJECTED** (crashes to the 300 mV anti-windup clamp, RMS 92–105 mV).
- **Add a branch-A slew term for the startup undershoot** — **REJECTED** (2nd expert panel, unanimous: WRONG SIGN — the coverage dip is minimized at SRa=∞; a positive SRa makes the already-over-predicted dip catastrophically worse, 245→1047→4456 mV). **ENFORCED IN CODE 2026-07-02:** the retirement was originally done only by stripping the manifest knob (`7b76d8b`), but the `_fit_slew_a` AUTO-fit (`46f1b30`) survived and silently re-introduced a fitted slew whenever a transient mapped — and a slew rail DROPS the Route-1 unload-discharge + derived ovVdz at emit (mutually exclusive branch-A forms; masked only by minimal-emit). So the auto-fit is now **OPT-IN, default OFF** (`_fit_voltage_output(..., slew_autofit=False)`; re-enable per-rail via `v_out[rail]['slew_autofit']` or globally via `coverage.slew_autofit`). The explicit manifest `slew_a` stays the hand-tuned escape hatch and overrides either way. `_fit_slew_a` is kept + unit-tested; `harness/test_slew_core.py` locks default-OFF + opt-in + the trap-closed guarantee (non-minimal emit keeps ovVdz/discharge).
- **Fit anything to real_V** — **REJECTED** (overfit 2.47→35.5 mV held-out; real_V is a turn-on/cold-start ENVELOPE, corr(I,V)≈0, NOT a load transient → reference-only, never a gate).
- **Higher-order ladder Zout** (above) — **WORKS** — is the load-transient fix from the standard flow.
- **UNLOAD-overshoot: branch-A DISCHARGE (Route 1)** — **WORKS / SHIPPED (2026-07-01).** The fit-inductor L_a stores ½L·I² of the DC load current, so a hard UNLOAD kicks the rail up (behavioral tank, lossless). The lesson first: **an OUTPUT-side clamp cannot fix it** (see §Refuted) — because dI_L/dt = V_across_L/L_a, clamping the overshoot small ⇒ small inductor voltage ⇒ slow drain, so overshoot-depth × recovery-time is ~constant. Route 1 instead DRAINS the inductor: a series term in the RESISTOR-form branch-A regulation `V(regnode,vrg) <+ R_a·I + gate(vov)·srcblk(I)·ovVmax·tanh((ovR/ovVmax)·I)`, a **voltage-BOUNDED reverse EMF** applied to the whole series inductor chain that forces dI_L/dt strongly negative INDEPENDENTLY of the (bounded) overshoot → both axes beat the clamp. Three properties make it safe, each load-bearing: (1) **gate = one-sided deadzone in the overshoot** `(vov>ovVdz)?tanh((vov−ovVdz)²/ovVsc²):0`, vov=V(o,vrg): ZERO value AND slope at the OP (which sits at vov<0 for every load) → Zout/PSRR/noise/DC BIT-identical (Spectre 0.0000 %), and one-sided ⇒ the loading dip is untouched; (2) **srcblk = `0.5(1−tanh(I/ovIsc))`** ~1 when branch A SOURCES (the unload energy dump), ~0 when it SINKS a sustained current ⇒ a +40 mA floating-rail abuse-sink never engages it; (3) **the reverse EMF is clamped to ±ovVmax** ⇒ the regulation ALWAYS keeps conductance ~1/R_a, so the DC pin can NEVER be de-pinned — the crucial contrast with the reverted "DC current compliance" (a zero-conductance current clamp that de-pinned → FF runaway; see §PVT). Defaults ovR=4 kΩ, ovVmax=2 V, ovVsc=8 mV, ovIsc=1 mA; **`ovVdz` is now AUTO-DERIVED per-rail** (`harness/fit_ovvdz.derive_ovvdz`, folded into `fit_multiport`, PURE-PYTHON, NO sim — mirrors `derive_iassist`): `ovVdz = clamp(2.5·max_f|Zout|·di_ripple [+ opt-in spur/PSRR], [5 mV, 0.5·(supply−vreg)])`, `di_ripple = 0.10·I_op` (the coverage periodic-ripple di, NOT the big assist step). Reproduces the former hardcoded 25 mV as the real part's special case (PLL 24.6 mV = 2.5·50 µA·197 Ω, VCO 26.1 mV = 2.5·200 µA·52 Ω); `emit_pmu_model._OVD_VDZ`=25 mV is now only the FALLBACK when a rail carries no characterized Zout (legacy/single-OP), and a manual `vfit['unload_discharge']['ovVdz']` still wins. This generalizes the floor to a DIFFERENT LDO (bigger ripple / smaller headroom / different L) instead of hard-coding this chip's value. **`ovVdz` is a LARGE-SIGNAL TRANSPARENCY FLOOR, not a DC-droop margin** (an adversarial-review finding, local-Spectre-confirmed): the dump engages for ANY excursion above vreg+ovVdz while branch A sources — which includes the positive half of a large-signal PERIODIC ripple, not just the one-time unload. Since the model's PRIMARY product is the spur/PSRR/Zout SPECTRA, ovVdz must sit ABOVE the largest legitimate periodic rail excursion or the dump clips those peaks and distorts the spectra (Spectre: ovVdz=3 mV → **16 mV clip-distortion** on a 20 mV-above ripple; ovVdz=25 mV = 2.5× the ~10 mV documented char → **0.002 mV**, transparent). Result (local Spectre, deployed params, 4 mA→0.3 mA/1 ns/20 pF): **PLL +302 mV(>supply)/~2 µs → +34 mV(≤supply), monotone settle (no 4 µs hang); VCO +124 mV → +28.5 mV**, no chatter; HB+PSS converge; survives minimal; +40 mA pinned at 0.824 V. TRADE-OFF: ovVdz is also where the overshoot SETTLES, so sub-µs-to-5mV recovery (which needs ovVdz<5 mV) was traded for the spectral transparency of the model's primary function — the fix still kills the two real pathologies (above-supply kick + 4 µs hang). BAKED localparams (INTERNAL, default-ON on the resistor regulation; slew rails keep slew()+Imax); per-rail `vfit['unload_discharge']` disables/retunes (lower ovVdz IFF the rail's large-signal ripple is known < that floor). `emit_pmu_model._ovd_*`; `harness/test_unload_discharge_core.py` (incl. a ripple-transparency guard). Numbers: DATA §5.
- **User TB-side fix: redesign the output iload as a STEP 600µA→300µA** (bakes steady loading into the DC-OP → pre-charges the fit-inductor → no phantom upward slew) — **WORKS** (resolved the startup drop, user-scoped). Caveat: stimulus-side fix; the big-inductor IC fragility (droop depth set by the IC, not physics) remains — record the 600µA choice.
- **Compressive branch-A current-assist `i_assist = iaG·tanh(verr·|verr|/iaV²)`** (verr=vreg−vout; ODD, f'(0)=0 EXACT → AC/PSRR/noise bit-identical at OP — verified 0.004 dB; saturates at iaG = class-AB loop stiffening; 2 params fit Spectre-in-loop, held-out across amplitudes) — **WORKS / SHIPPED (PART2)** — the fix for the GT sub-linear stiffening dip; replaces the LINEAR over-prediction (163.6 mV/mA) with the SUB-linear silicon shape. Fitted PLL (iaG=2.8 mA, iaV=0.33 V) → dips 154/224/290 mV vs GT 160/227/282, held-out middle −3.7%, full-waveform GT-RMS 10–16 mV (was 24–69); VCO (iaG=4.0 mA, iaV=0.22 V) → 74/103/129 vs GT 74.7/103.4/128.7 (rms 0.9 mV). BAKED localparams (INTERNAL physics → SURVIVES minimal-emit; minimal minimizes the SCHEMATIC param set, not the model — adds NO CDF param). Manifest override `m['v_out'][rail]['iassist']={iaG,iaV[,floor,gfloor]}` → `_fit_iassist` → emit (mirrors slew_a/recovery escape-hatch; absent → byte-identical). Optional `floor` = a DEEP out-of-envelope backstop (one-sided clamp below `floor` V, zero value+slope above → invisible in the validated regime) so a system sim never sees a negative rail far past VALID_LOAD where the saturated assist can't hold — the assist is the CURE, the floor is a SEATBELT (NOT the rejected "crashes-to-clamp" primary mechanism). Residual GT-RMS conflates genuine compression with the documented T-confound (AC z_pll=tt_25c, step GT=tt_55c, ~×0.65) — a T55 z re-export would clean the absolute gain. **STANDARD-FLOW DERIVATION — PURE-PYTHON, NO SIMULATOR** (`harness/fit_iassist.py`, folded INTO `fit_multiport`): the model's load-step dip is NOT re-simulated — it is a small KNOWN linear RLC network (branch-A ladder + external decap) with one nonlinear feedback (the assist), so `predict_dip` solves it as an ODE (LSODA, ~2 ms/solve, validated <1.6 mV vs Spectre on both rails). `derive_iassist` reads the coverage.transient GT dips already in the npz (`tr_*`, from the FIRST ALPS/Donau run) and `fit_rail` solves iaG/iaV against them (grid+refine, minimal-intervention tie-break, held-out) — at the first fit, no second simulation, runs on box/GUI/CI. Re-derives PLL ≈4.6 mA/0.44 V (−1.2% held-out), VCO ≈7.2 mA/0.31 V (0.0%) with the seed hidden; whole derive ≈5 s. The manifest `iassist` is a SEED used only when the npz has no `tr_*` (legacy/single-OP). (The earlier Spectre-in-loop version was REMOVED — company policy forbids local Spectre; only ALPS/Donau or pure-Python.) The 2 params are **partly degenerate** (a valley matches the same dips → gate on dip-RMS+held-out, not the values). Diagnostic FACT: the negative-trans is purely LOAD-driven — supply (0.85–1.15 V) and temp (−40–125 °C) move it 0 mV; higher vreg is SAFER (min=vreg−dip); "FF"/"VDD>0.8" only correlate via the real load drawing more current.
- **UNLOAD-overshoot `ovVdz` AUTO-DERIVE from a MEASURED overshoot (Option A) — WORKS / SHIPPED (2026-07-02).** The prior `ovVdz` derive was a ripple PROXY (`2.5·max|Zout|·di_ripple`) never anchored to a measured overshoot, so it sat BELOW real operational excursions and CLIPPED them (the "silicon ~50 mV vs model ~26 mV" gap). OP-inert → composite bit-identical for any fitted value. Validated vs local Spectre (dev-only): DATA §5.
- **Direction, NOT label (transient step routing) — INVARIANT.** Every `coverage.transient` step's direction = `sign(i_to − i_from)` taken from the manifest `tr_steps` DECLARATION — NEVER string-parsed from the opaque label. `gt_dips_from_npz` keeps LOAD steps only (`vref−min(Vout)`, feeds the compressive assist); `gt_overshoots_from_npz` is the UNLOAD dual (`max(Vout)−vref`, feeds the ovVdz overshoot derive); `derive_iassist` filters to loading steps so an unload step can never poison the assist fit. `_tr_step_pairs` maps npz `tr_<rail>_*` keys to (from,to) mirroring importmp's dual-label / load-suffix matching. This dropped the old shared-baseline (`steps[0].from`) + `<N>m`-label parse.
- **Two-layer safety net — FRAMING.** The LTI Zout is the workhorse for the whole normal operating band (any stimulus, via its impedance). The nonlinear layer (compressive assist / unload-discharge / floor) is a LARGE-EXCURSION SAFETY NET — it must engage ABOVE the largest legitimate operating excursion, never inside it. The overshoot auto-derive enforces this on the unload side (ovVdz ≥ max operational overshoot); the assist f'(0)=0 and the discharge gate 0-value+slope-at-OP enforce it on the small-signal side.

- **Identifiability holds a grade only when the freedom MATTERS (pmukit, 2026-09-24)** — **ADOPTED; the earlier "any flag caps at yellow" is REFUTED as too strict.** The gate's column-norm / sigma tests answer *does the data leave this number free?*; the hold must answer *can that freedom mislead a consumer?*. They differ: on the fake demo PMU every Zout / PSRR / noise / bias-idc cell was held (Rpl, G0, amp_i[k], the knee), so no cell could read OK — while the scores sat at 0.04 dB against a 1 dB limit. Held iff that influence exceeds the metric's green limit (1 dB spectral, 2 dB noise); an unmeasured flag (older fits, DC / large-signal blocks) still holds. When the envelope reaches past the data, EVERY parameter is measured, so an unflagged one the band sees only at the 1 % level but that decides the envelope (a flicker corner below the first noise point, a feedthrough above the last PSRR point, an ESR above the last Zout point) holds too — the rule is tighter than before there. REASONING: the small-signal blocks are baked at ONE cell (no cross-cell interpolation of these numbers), so a free number can only mislead through the frequencies the model is used at; where the data covers them, "free" means by construction "cannot change the answer by more than the data tolerance". ## What the pmukit refactor changed (2026-09-15/16)

The METHOD above is carried over unchanged -- it is validated, and the refactor deliberately did
not touch the numerics. What changed is everything around it:

- **The data contract.** String-keyed npz (`tr_<rail>_2m_tt_25c`, opaque `L0..L5` labels) is
  replaced by a dimensioned dataset (`process x temp x vset x load x sweep`) in which NaN means
  "no data" and `coverage()` separates *never run* from *ran and broke*. The fitter can finally
  see the difference, which the old flow could not express.
- **The plan is derived, not configured.** `spec.py` holds the physics inventory (which block
  needs which observable on which axes); `plan.py` inverts it. Every run carries the
  `(port, block, parameter)` triples it feeds, so "why does this run exist?" is a lookup. Runs one
  simulation can produce together are merged -- the rail PSRR and the bias PSRR are literally one
  supply injection.
- **Resume is a property of the identifier.** `run_id` is a content hash of
  (netlist sha, corner, analysis, stimulus, cell); re-planning an unchanged run collides with the
  finished one. There is no separate cache to get out of sync.
- **PVT route A is enforced by construction.** Each process corner is characterized and fitted
  separately and emitted as its own `.scs` section; there is no cross-PVT interpolation surface to
  overfit. (The one exception stays the one the method always allowed: a continuous PTAT-ish i(T)
  inside a corner.)
- **One emitter, one simulator family.** ngspice is retired and the `.lib` twin with it, so the
  cross-engine byte-lock that justified some past choices no longer applies -- notably the
  rejection of Verilog-A's native `flicker_noise()`, whose *stated* reason was the absence of a
  byte-matching ngspice analog. The validated Lorentzian bank remains the default; re-opening that
  choice now needs new evidence, not just the disappearance of the old constraint.
- **The refuted list is code, not folklore.** `spec.NOT_MODELED` carries REFACTOR_PLAN 6.2's
  exclusions, and the emitter's primitive whitelist carries the HB-convergence scars, each with
  the failure that produced it. A future contributor has to argue with a test, not with a memory.

**Still open, carried over unchanged:** validation independence (the analytic `predict()` shares
transfer functions with the fitter), the leave-one-corner-out interpolation gap at few corners,
and noise correlation between a shared reference's rail and bias paths (a known ~3 dB error
source, not yet measured on silicon).

## Refuted — do NOT re-attempt

- Two-notch PSRR in a single-loop integrated LDO (physics).
- Strong negative-Re Zout in a passive RLC (representational floor ~−0.25 Ω).
- A clean blind-spot B1 (collinear CTAT+PTAT, bowed interior, clean I-V) in this CTAT-Vth BSIM3 PDK (a hard 3-way tension; documented FALLBACK, monotonic-convex isrc kept).
- A fitter-layer fix for multi-pole PSRR grid sensitivity (R7 negative — if a fit looks PSRR-limited, the fix is recipe-side tone/grid placement).
- Joint-LS Cout/ESR for high-ESR/cap-less parts (underdetermined).
- The branch-A slew term for the startup undershoot (wrong sign).
- Fitting to real_V (it's a turn-on envelope, overfits).
- **A symmetric current-compliance-knee gate `|vhi−Vo|` (sqrt-of-square)** — it climbs the gate back to 1 beyond the ceiling → the sink REOPENS to full current above vhi (and below ground for the 'lo' form), non-physical (the device is starved past its compliance limit). The knee must be ONE-SIDED (`max(.,0)`); see §Current-output. This was an emit-vs-fit inconsistency (the Python fit/score gate was already one-sided via `clip(arg,0)`).
- **An OUTPUT-side clamp for the branch-A UNLOAD overshoot** (high-side clamp at the supply, or any clamp on vout). It CANNOT win: with a lossless fit-inductor, dI_L/dt = V_across_L/L_a, so bounding the overshoot small forces a small inductor voltage ⇒ a slow drain — overshoot-depth × recovery-time is ~constant (local-Spectre: an output high-side clamp bounds +302 mV→+24 mV but HANGS 4.7 µs; the `himargin` symptom-fix was likewise not shipped). The energy must be removed at the INDUCTOR (source-gated bounded reverse-EMF discharge, §Large-signal Route 1 — WORKS), not clamped at the output.
- **A symmetric branch-A discharge / any discharge gated on the overshoot ALONE** (no source/sink discriminator, or an unbounded series resistance). Local-Spectre: an unbounded series dump-R de-pins the DC — a +40 mA floating-rail sink drives the saturated dump to a zero-slope high-R and the rail RUNS AWAY to 142 V (the same de-pin failure as the reverted "DC current compliance"). The fix must be (a) BOUNDED in voltage (keeps 1/R_a conductance) AND (b) SOURCE-gated (`srcblk`, so a sustained sink never engages it) — see §Large-signal Route 1.
- **A SMALL unload-discharge deadzone `ovVdz` (~mV) tuned for sub-µs recovery** — the deadzone is NOT free to minimize. The dump engages on the positive half of a large-signal PERIODIC ripple too, so an ovVdz below the validated large-signal ripple CLIPS the spur/PSRR/Zout spectra the model exists to produce (local-Spectre: ovVdz=3 mV → 16 mV clip-distortion on a 20 mV-above ripple). `ovVdz` is a TRANSPARENCY FLOOR (default 25 mV, above the ~10 mV char); sub-µs-to-5mV recovery (needs ovVdz<5 mV) is the sacrificed axis. There is no memoryless gate that both arrests the ns-scale unload PEAK and ignores a same-timescale periodic ripple.
- **A STATEFUL / memory unload-discharge gate (leaky-integral of the overshoot; or a gyrator realization exposing the inductor-current state) to recover sub-µs settling WITHOUT clipping periodic ripple** — **REFUTED (local-Spectre, reduced PLL branch-A `Ra 0.095Ω + 22.9µH/43Ω + 4.42µH/155Ω`, 2026-07-01).** It fails BOTH axes at once: (1) **cannot bound the ns peak** — the memory (τ) lags the ~5–13 ns overshoot peak, which then escapes ABOVE supply (+225…+432 mV at τ=50–200 ns vs the shipped instantaneous +35 mV), losing Route-1's primary function; (2) **transparency is frequency-limited** — transparent only when ripple f ≫ 1/τ (clip vs bare: τ=200 ns → 0.000 mV @20 MHz but **18.8 mV @2 MHz**, as bad as the naive ovVdz=3 mV), and 2 MHz IS a spur band. The two demands CONFLICT (larger τ → better transparency, worse peak capture). This is the **DUAL** of the memoryless result above: *a memory gate that ignores ripple is inherently too slow to arrest the ns peak.* ⇒ in the single-output-node-gate space the shipped **instantaneous ovVdz=25 mV gate is Pareto-optimal** (bounds peak + fully transparent, cost = the ~1.8 µs passive tail); sub-µs recovery is a FUNDAMENTAL cost, NOT a realization artifact — a **gyrator / state-space realization would NOT help** (the bottleneck is gate DISCRIMINATION, not the L realization; the drain is already fast once open). The one architecture that gets sub-µs recovery + transparency + peak-safety together is a **gray-box loop model** (pass-device can't-sink bounds the peak; loop BW sets recovery; NO gate → no distortion) — a large rebuild with HB-convergence risk, justified only if unload-timing fidelity is a deliverable. Reduced-model TB `scratchpad/heavy/` (not committed); numbers DATA §5.
