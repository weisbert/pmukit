# 决定簿（overnight build）

> 规矩：不问用户，拿不准自己定，一行一条：**决定 · 原因 · 可逆吗**。
> 「可逆」= 改掉它要动多少东西：**易**（改一个常量/参数）、**中**（改一个模块 + 测试）、**难**（动契约或数据格式）。
