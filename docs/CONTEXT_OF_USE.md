# 使用情境（ISO 9241-210 第一步，一页纸）

## 用户是谁

**主用户：子模块设计师。** VCO / PLL / 接收机的设计师，PMU 对他是黑箱。他要的是一个能放进自己 HB / 相噪 / 瞬态仿真的 PMU 模型，跑得快、不炸、在他跑的角和温度下和真电路差不多。他不会看拟合参数，会看"能不能信"和"哪里没跑"。

**次用户：PMU 建模者（就是我们）。** 在盒子上跑表征、在桌面上调试和复现。他要看每条 run 怎么跑的、失败日志、配方、摘要，会用右键和 CLI 回显。

**旁观者：主管和评审。** 只读 report.md 的第一段和绿黄红表。

## 什么时候用

- 一个新芯片或新 PMU 交付件到手，子模块设计师第一次要用模型。频率：一个项目一到两次。
- PMU 改版、PDK 换角、VSET 档变：重新表征。频率：一个项目几次。
- 客户仿真不收敛或结果对不上：建模者拿摘要回桌面复现。频率：随机，最紧急。

## 前后接什么

前：ADE 里按约定搭好测试台，导出一份网表。后：交付目录里的 `.scs` 库加进 corner 设置，`.va` 实例放进自己的台子。出问题时：Copy for desk → relay → 桌面 agent。

## 环境约束

- 盒子：RHEL8、tcsh、无网络、无 agent、Firefox 可用、Python 3.11 venv、Donau 队列、ALPS/Spectre。
- 桌面：Windows + Linux VM，有 Spectre 18.1、有 agent、有网络，但没有客户数据。
- 数据不能进公开仓；跨机器只能靠粘贴文本。
- 用户一天里在 ADE 和终端之间切换，习惯 CIW 命令回显和 tcsh 脚本。

## 成功是什么样

子模块设计师从拿到网表到把模型放进自己台子，不问建模者一个问题。建模者收到一条"模型在我这儿不收敛"，只用一份摘要就能在桌面复现。
